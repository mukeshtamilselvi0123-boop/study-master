STUDY MASTER - FREE ANDROID PWA STARTER

Files:
- index.html: the app
- manifest.json: installable app details
- sw.js: basic offline cache

To install as an Android home-screen app:
1. Upload these files to a public GitHub repository.
2. In GitHub, open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the HTTPS site.
5. Open the published HTTPS link in Chrome on Android.
6. Chrome menu (three dots) > Install app or Add to Home screen.

Alarm note:
A browser-based app cannot guarantee a wake-up alarm after Android closes/suspends it.
Set the 4:00 AM repeating alarm in Android Clock as well.

Sleep note:
For teenagers, recommended sleep is 8-10 hours. A 9 PM finish followed by a
4 AM wake-up provides only 7 hours. Please shift bedtime/study timing to protect sleep.
